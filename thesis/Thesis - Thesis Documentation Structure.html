\chapter{Introduction}

\section{Background}

Diffusion models have become a powerful approach for image generation and editing because they can synthesize visually realistic images from text prompts and other conditioning signals. However, precise structural editing remains a difficult problem. Many existing image-editing methods can modify appearance, style, or semantic attributes, but they often struggle when the user wants to move an object, reshape it, or control its position in a specific and measurable way.

Motion-guided image editing addresses this limitation by using a target motion field to guide the editing process. Instead of relying only on text descriptions such as ``move the object to the right'', the image is edited according to a motion signal that describes how pixels or object regions should move. The Motion Guidance method introduced this idea by using differentiable optical-flow estimation inside the diffusion sampling process \cite{geng2024motion}. This allows the generated image to be guided toward a desired motion while preserving visual similarity with the source image.

\section{Problem Statement}

Although Motion Guidance provides a strong baseline for motion-based image editing, its practical controllability is limited when the user must depend mainly on precomputed dense target flows. Creating such flows can be difficult for non-expert users, and direct primitive control such as translation, scaling, stretching, or rotation is not fully supported in a simple user-facing pipeline. In addition, motion guidance alone may produce unstable results, weak displacement, source-hole artifacts, or background inconsistencies after object movement.

Therefore, the central problem addressed in this thesis is:

\begin{quote}
How can diffusion-based motion-guided image editing be made more controllable and practical by introducing explicit motion primitives, localized guidance, hard geometric initialization, and post-diffusion restoration?
\end{quote}

\section{Research Motivation}

Precise object-level image editing is important in creative design, visual prototyping, media editing, and human-controlled generative systems. Text prompts alone are often ambiguous for spatial manipulation. For example, a command such as ``move the apple to the right'' does not specify the exact displacement, object support, background repair strategy, or boundary handling.

A controllable editing system should allow the user to define motion using explicit parameters such as displacement, scale factor, stretch factor, or rotation angle. It should also preserve the original appearance of the object and repair the background region exposed after the object has moved. This motivates a pipeline that combines motion primitives, diffusion refinement, and restoration-based post-processing.

\section{Aim and Objectives}

The aim of this thesis is to develop and evaluate a controllable extension of Motion Guidance for image editing using explicit motion parameters and restoration-aware refinement.

The main objectives are:

\begin{enumerate}
    \item To reproduce and study the original Motion Guidance baseline for diffusion-based image editing.
    \item To generate target motion fields from explicit motion primitives such as translation, scaling, stretching, and rotation.
    \item To apply selective refinement so that guidance is stronger inside the edited object region and weaker outside it.
    \item To use hard warp initialization to improve the effectiveness of object displacement before diffusion refinement.
    \item To integrate background restoration and sharp compositing to reduce source-hole artifacts.
    \item To develop a practical frontend and backend interface for running controlled motion-guided editing experiments.
    \item To evaluate the proposed pipeline using qualitative results, quantitative criteria, ablation analysis, and honest limitation analysis.
\end{enumerate}

\section{Research Contributions}

This thesis makes the following contributions:

\begin{enumerate}
    \item A controllable motion-primitive interface for generating target flows from user-defined geometric parameters.
    \item A selective refinement strategy that applies different guidance strengths inside and outside the object mask.
    \item A hard warp initialization step that improves rigid object movement before diffusion-based refinement.
    \item A modular restoration pipeline using local filling, patch-based restoration, OpenCV inpainting, and LaMa-based restoration.
    \item A sharp compositing strategy for preserving object texture after motion-based editing.
    \item A FastAPI and Next.js based demonstration system with preset examples and before-after visualization.
    \item A practical evaluation of strengths and limitations, showing that the method is strongest for controllable rigid object translation.
\end{enumerate}

\section{Scope of the Study}

The scope of this thesis is limited to single-image motion-guided editing using a diffusion model, optical-flow-based guidance, and object-level motion primitives. The work focuses mainly on controlled rigid translations and selected geometric transformations. Examples such as apple and teapot translation are treated as the strongest evidence for the proposed pipeline. More difficult non-rigid examples, including hair growth and topiary deformation, are discussed as unstable cases and are not treated as the main proof of generalization.

The thesis does not claim to introduce a new diffusion model or a new optical-flow network. Instead, it extends an existing Motion Guidance framework into a more controllable and practical editing pipeline.

Chapter 3 explains the original Motion Guidance baseline. Chapter 4 presents the proposed controllable motion-guided editing pipeline. Chapter 5 describes the system architecture and implementation. Chapter 6 explains the experimental setup and evaluation criteria. Chapter 7 presents the results. Chapter 8 provides the ablation study. Chapter 9 discusses limitations and future work. Chapter 10 concludes the thesis.
