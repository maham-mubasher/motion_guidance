Introduction
CONTEXT
Image Editing

Generative models create realistic images, but exact spatial control is difficult

Text is semantic

Prompts describe what should appear, but not the exact pixel displacement.

Editing needs geometry

Object motion requires location, direction, magnitude, and object support.

Scenes must remain stable

The moved object, background, boundaries, and identity should remain coherent.

Research focus: control a pretrained diffusion model with an explicit motion signal.

Problem Statement
RESEARCH QUESTION

How can a pretrained latent diffusion model follow explicit object motion without retraining?

Original Motion Guidance depends on prepared dense flow fields.
Soft guidance can be weak for large displacement.
Moving an object exposes a missing background region.
Unedited regions can drift during stochastic generation.
Control = target motion + learned image prior + source preservation

ML Background
OPTICAL FLOW

RAFT converts visual change into dense motion

RAFT input

Source image and current decoded diffusion prediction.

F̂ = RAFT(xsource, xcurrent)

RAFT role

Estimates displacement for every pixel.
Compares generated motion with target motion.
Remains inside the PyTorch computation graph.
Sends gradients back to the diffusion latent.

Proposed Method
GUIDANCE ENERGY

Two losses control motion and appearance

Flow loss

Matches RAFT-predicted motion with the target field.

Lflow = MAE(F̂, F)

Color loss

Warps the current prediction and compares it with the source.

Lcolor = MAE(x0, W(x, Fwarp))
E = λfLflow + λcLcolor

Restoration
SOURCE-HOLE PROBLEM

Motion creates a second problem: missing background

The original object location becomes disoccluded.
RAFT guidance describes motion, not the hidden background.
Optional LaMa adds learned large-mask inpainting.
OpenCV and patch-based methods provide non-ML alternatives.

Important separation

Motion guidance: where content should move.

Restoration: what should appear behind it.

Compositing: how the sharp source object is placed in the final contained-translation result.

Limitations and Interpretation
HONEST SCOPE

What I can claim

RAFT has a measurable pre-composite contribution.
Primitive control and initialization make large translation operational.
Apple and teapot show stable contained translation across three seeds.
RAFT iterations and restoration choice measurably affect the apple case.

What I cannot overclaim

Final contained translations are not pure diffusion outputs.
The full RAFT ablation is still one object, background, mask, and motion size.
The hyperparameter study is compact, one-factor-at-a-time, and single-seed.
Tree shows non-rigid/file-flow behavior is less stable.
Best answer: RAFT improves diffusion alignment; restoration and compositing deliver final visual quality.
CONCLUSION
Main Takeaway

RAFT-guided diffusion helps the trajectory; hybrid compositing makes the final edit clean

My contribution is an auditable extension of Motion Guidance: primitive-generated flow supervision, spatial latent control, stronger initialization, source preservation, restoration-aware processing, fixed-seed ablations, compact sensitivity analysis, and restoration evidence.
